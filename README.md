# 豆绘

一个在浏览器本地运行的拼豆图纸生成工具。上传图片、选择网格尺寸，即可获得内置通用色卡匹配的拼豆图纸。

## 功能

- PNG、JPEG、WebP 图片转拼豆网格
- 16×16、29×29、32×32 预设与 1–120 自定义网格
- 点击色卡或任意豆子，高亮同色豆子
- 显示色号、颜色名称和数量统计
- 导出含网格与色号清单的 PNG 图纸
- 所有处理都在浏览器完成；图片不会上传到服务器

## 本地运行

```bash
npm install
npm run dev
```

运行检查：`npm run test`、`npm run build`。

## 开源协议

MIT。色卡为通用近似色卡，不代表任何拼豆品牌的官方色号。
